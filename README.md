# Princess Day Surprise

A one-page romantic website. Everything (styles, script, photo) is inside `index.html`.

## Put it online with GitHub Pages
1. Create a new repository on github.com (it can be Private only on paid plans; Public is fine, the link is unlisted unless you share it).
2. Click "uploading an existing file", drag in `index.html`, `.nojekyll` and `README.md`, then Commit.
3. Go to Settings > Pages. Under "Build and deployment", set Source to "Deploy from a branch", Branch to `main` and folder `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

To update later, upload a new `index.html` to the same repository and commit.
